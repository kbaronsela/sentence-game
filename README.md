# משחק המשפטים

משחק סיפור משותף בזמן אמת — כל שחקן רואה רק את המילה האחרונה מהתור הקודם (כמו דף מקופל).

## הרצה מקומית

```bash
npm install
npm start
```

פתיחה: <http://localhost:3456>

## פריסה (Render)

הפרויקט כולל `render.yaml`. חברו מאגר ל-[Render](https://render.com) כ־Blueprint או Web Service — פקודת הפעלה: `npm start`.
